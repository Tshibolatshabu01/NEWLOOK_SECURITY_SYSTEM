# NEWLOOK SaaS V12.2 — Enterprise Structured Rebuild

## Source of truth
The existing NEWLOOK V10 application structure is preserved. This release does not replace the functional Admin, Guard, Attendance, Payroll or Super Admin applications with demo implementations.

## Rebuilt domains
- Customer/Admin SaaS
- Super Admin platform
- Guard application
- Attendance application
- Payroll application and existing payroll engines
- SaaS authentication and company session
- Device registration/setup and one-time device activation
- Existing reports, operational modules, finance, treasury, statutory and payslip modules

## Architecture
Existing entrypoints remain intact while shared services provide controlled boundaries:
- `SaaS/core/repository.js`
- `SaaS/core/tenant.js`
- `SaaS/core/access.js`
- `SaaS/core/audit.js`
- `SaaS/appKernel.js`
- `SaaS/apps/*/service.js`

## Data rules
`users/{uid}` remains the account identity source of truth.

Tenant data remains under `companies/{companyId}/...`.

Payroll source separation is preserved:
- Security → Guard → `shiftRecords` → Payroll
- Staff → Attendance → `attendanceRecords` → Payroll

`shiftRecords` and `attendanceRecords` are not repurposed as generic operational collections.
